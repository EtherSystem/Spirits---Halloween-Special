# Spirits - Halloween Special

*Apparently, killing something doesn't always mean it will leave you alone.*

**Spirits - Halloween Special** is a mod for **The Long Dark** that brings a little haunting to Great Bear Island. Wildlife can return as ghosts after being killed, spectral predators can appear out of nowhere, and you can even turn the island's usual inhabitants into ghostly versions of themselves.

Nothing says a relaxing walk through the wilderness quite like a ghost bear c:

## Features

### Ghosts of the dead

With **Ghost Spawns** enabled, animals killed by the player can come back as temporary apparitions near their bodies.

- Wolves, timberwolves, starving wolves, bears, moose and cougars may attack or flee.
- Deer, rabbits and ptarmigans always try to escape.
- An approaching ghost fades away as it gets close to you. Hitting one also makes it vanish.
- Ghosts cannot start a struggle with the player. They're already dead, there's no need to make things complicated eh?

Each species has its own opacity setting, so you can decide just how visible your unwanted visitors should be !

### Random predator ambushes

If waiting for something to die sounds too peaceful, you can enable **Random Ghost Ambushes**.

While you're outdoors, a ghost predator may appear behind you and charge. You can choose which predators are allowed: **wolves, bears, moose and cougars**. The delay between ambush attempts is configurable using in-game time, and the timer pauses while you're indoors or the game is paused.

This feature is **disabled by default** and works independently of the ghosts that appear after a kill.

### Ghost wildlife appearance

Want an entire region full of ghostly wildlife? You can give ordinary animals a translucent appearance without changing their normal AI or behavior.

This works with bears, wolves (including starving wolves), timberwolves, moose, cougars, deer, rabbits and ptarmigans. Each animal type has a separate opacity setting.

**Important:** This feature only changes how living animals look. A ghost-looking bear is still a bear, and it can still ruin your day.

## Console commands

For testing with **DeveloperConsole**:

| Command | Effect |
|---|---|
| `spirits_ghostbear` | Summon a ghost bear. |
| `spirits_ghostwolf` | Summon a ghost wolf. |
| `spirits_ghosttimberwolf` | Summon a ghost timberwolf. |
| `spirits_ghoststarvingwolf` | Summon a ghost starving wolf. |
| `spirits_ghostmoose` | Summon a ghost moose. |
| `spirits_ghostcougar` | Summon a ghost cougar. |
| `spirits_ghoststag` | Summon a ghost stag. |
| `spirits_ghostdoe` | Summon a ghost doe. |
| `spirits_ghostrabbit` | Summon a ghost rabbit. |
| `spirits_ghostptarmigan` | Summon a ghost ptarmigan. |
| `spirits_ambush` | Attempt an immediate random ghost ambush outdoors. |

The `spirits_ambush` command uses the predator species selected in the mod settings.

## Installation

1. Install **MelonLoader** and **ModSettings**.
2. Place the mod's DLL in your `Mods` folder.
3. Launch the game and adjust the options through ModSettings if desired.

**DeveloperConsole** is optional and is only needed to use the testing commands.
